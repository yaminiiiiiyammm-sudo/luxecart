## ✨ Features

- Premium modern e-commerce design
- Responsive desktop and mobile layout
- Product showcase with images
- Product categories
- Add to Cart functionality
- Dynamic cart count
- Remove products from cart
- Dynamic cart total
- Checkout screen
- Order summary
- Interactive UI
